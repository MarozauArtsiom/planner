# sprint-retro — фичи ретро-доски

Скоуп (решение PO, 2026-10-20): **только ретро-доска**. AI, health checks, poker, стендапы, интеграции — в To do на потом.
Целевой рынок: Европа и США. Обоснования — по исследованию в `knowledge/retro-market/`.

Приоритеты: **P0** — MVP, без этого доска не работает; **P1** — сразу после MVP, всё ещё в рамках доски.

## P0 — MVP

### Доска и шаблоны
- [ ] Создание доски фасилитатором (вход по email / Google).
- [ ] Участники входят по ссылке без регистрации, указывают только имя.
- [ ] Доска приватная по умолчанию (доступ только по ссылке-приглашению). Отличие от бесплатного EasyRetro, где доски публичные.
- [ ] 5–6 классических шаблонов: Went well / To improve / Actions, Start / Stop / Continue, Mad / Sad / Glad, 4Ls, Sailboat.
- [ ] Свои колонки: добавить, удалить, переименовать, поменять цвет.

### Сбор карточек
- [ ] Добавление, редактирование и удаление своих карточек.
- [ ] Анонимный режим: автор карточек скрыт.
- [ ] Приватный сбор: карточки скрыты (blur), пока фасилитатор их не раскроет.
- [ ] Real-time синхронизация и присутствие (кто онлайн, кто ещё пишет).

### Группировка
- [ ] Drag-and-drop между колонками и внутри колонки.
- [ ] Объединение карточек в группу с заголовком.

### Голосование
- [ ] Dot voting с лимитом голосов на человека (настраивается).
- [ ] Голоса скрыты до окончания голосования.
- [ ] Сортировка карточек и групп по числу голосов.

### Фасилитация
- [ ] Фазы ретро: сбор → группировка → голосование → обсуждение → действия. Фасилитатор переключает фазы, и для участников это включает или блокирует действия.
- [ ] Таймер на фазу со звуковым сигналом.
- [ ] Фокус на обсуждаемой карточке: подсвечивается у всех.

### Action items
- [ ] Action items с ответственным и сроком.
- [ ] **Перенос action items в следующее ретро команды:** в начале показываются прошлые действия со статусом (выполнено / нет). Ключевое отличие: у EasyRetro и многих других этого нет.

### Команда и история
- [ ] Пространство команды: участники и список прошлых ретро.
- [ ] Просмотр завершённых ретро (read-only).

### Экспорт
- [ ] Экспорт итогов в Markdown (копирование в буфер) и CSV.

### Платформа
- [ ] Хостинг в ЕС, базовое соответствие GDPR: политика конфиденциальности, удаление данных по запросу, DPA.
- [ ] Интерфейс на английском.
- [ ] Участник может работать с мобильного браузера.

## P1 — развитие доски после MVP
- [ ] Комментарии к карточкам.
- [ ] Реакции-эмодзи на карточках.
- [ ] Расширенная библиотека шаблонов и сохранение своих шаблонов.
- [ ] Экспорт в PDF / PNG.
- [ ] Права ролей: несколько фасилитаторов, участник, наблюдатель.
- [ ] ROTI-голосование в конце встречи (оценка полезности ретро).
- [ ] Блокировка доски после завершения и архивирование.
- [ ] Подсказки по фасилитации для новичков в каждой фазе.
