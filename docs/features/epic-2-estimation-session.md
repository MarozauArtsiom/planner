# Эпик 2: Сессия оценки (Estimation Session)

## Бизнес-цель

Обеспечить совместную оценку задач командой через голосование по 4 критериям (Dev Effort, QA Effort, Risk, Uncertainty) с автоматическим расчётом Story Points и пропорции Dev/QA. Scrum Master управляет процессом: выбирает тикет, раскрывает результаты, принимает оценку. Участники голосуют с мобильных устройств, изменения отображаются в реальном времени через HTTP polling.

## Что реализовано

### Story 2.1: Управление активным тикетом
- SM создаёт тикеты (ID, название, описание, AC, ссылка на трекер) через боковую панель.
- SM выбирает тикет для оценки — он мгновенно отображается на экранах всей команды.
- Кликабельная ссылка на внешний трекер (если задан `externalUrl`), название и Acceptance Criteria.
- Polling с интервалом 5 секунд обеспечивает автоматическое обновление экранов Dev/QA.

### Story 2.2: Голосование по 4 критериям
- Mobile-first интерфейс опросника с крупными тач-кнопками.
- 4 критерия с цветовой кодировкой:
  - **Dev Effort** (indigo): 1, 2, 4, 6
  - **QA Effort** (emerald): 1, 2, 4
  - **Risk** (amber): 0, 1, 2
  - **Uncertainty** (violet): 0, 1, 2
- После отправки голоса UI показывает статус «Ожидание команды» с прогресс-баром.
- SM видит прогресс голосования (X / Y проголосовали) и может раскрыть результаты.

### Story 2.3: Калькуляция результатов
- **Медиана** баллов по каждому критерию среди всех проголосовавших (вместо среднего).
- Конвертация суммы медиан в SP: 2-3 = 1 SP, 4-5 = 2 SP, 6-8 = 3 SP, 9+ = 5 SP.
- Расчёт пропорции Dev/QA (medDevEffort / (medDevEffort + medQaEffort)).
- Визуализация: SP-бейдж, горизонтальная шкала пропорции, прогресс-бары по критериям.
- SM может принять оценку или переголосовать. При принятии SM выбирает значение SP из ряда `1 | 2 | 3 | 5 | 8 | 13` — рекомендованное предвыбрано, но можно выбрать любое.

### Story 2.4: Детализация голосов
- После раскрытия результатов **все участники** видят таблицу «Голоса команды» — кто как проголосовал по каждому критерию.
- **SM дополнительно видит:** строку медианы, подсветку высокого Risk (amber), детекцию выбросов (IQR-метод, красный бордер + бейдж «Выброс»).
- Клик на оценённый тикет в sidebar открывает модал с полной статистикой (результаты + таблица голосов).
- SM в модале может переоценить тикет или изменить SP через Fibonacci-selector.

### Story 2.5: Импорт тикетов из CSV
- SM может массово импортировать тикеты через модальное окно в сайдбаре оценки.
- Два способа ввода: вставка текста в textarea или drag-and-drop / выбор CSV-файла.
- Поддерживаемые колонки: `externalId`, `title` (обязательно), `externalUrl`, `description`, `acceptanceCriteria`.
- Разделитель (запятая или табуляция) определяется автоматически. Первая строка трактуется как заголовок, если совпадает с известными именами колонок.
- Перед импортом отображается таблица предпросмотра с подсветкой ошибок валидации.
- Парсинг CSV выполняется на фронтенде (papaparse), бэкенд принимает массив объектов и создаёт тикеты через `prisma.ticket.createMany()`.

## Ключевые файлы

| Файл | Назначение |
|---|---|
| `prisma/schema.prisma` | Модели EstimationSession, Vote, Ticket (devEffortProportion) |
| `src/lib/estimation-engine.ts` | Расчёт медиан, SP, пропорции Dev/QA |
| `src/lib/csv-parser.ts` | Парсинг CSV/TSV, маппинг колонок на поля тикета, валидация |
| `src/components/estimation/vote-details.tsx` | Таблица индивидуальных голосов с outlier-детекцией |
| `src/components/estimation/ticket-import-modal.tsx` | Модал импорта CSV: drag-and-drop, textarea, предпросмотр |
| `src/app/api/estimation/ticket-stats/route.ts` | API статистики любого тикета (не только активного) |
| `src/app/actions/estimation.ts` | Server actions: createTicket, importTickets, setActiveTicket, submitVote, revealVotes, acceptEstimation, restartVoting, deleteTicket |
| `src/app/api/estimation/session/route.ts` | GET-эндпоинт для polling (состояние сессии, активный тикет, голоса, результаты) |
| `src/hooks/use-estimation-polling.ts` | Клиентский хук для polling с интервалом 5 сек |
| `src/app/project/[id]/estimation/page.tsx` | Server-компонент страницы оценки (project-scoped) |
| `src/components/estimation/estimation-board.tsx` | Главный клиентский компонент (layout, sidebar, состояния) |
| `src/components/estimation/voting-form.tsx` | Mobile-first форма голосования по 4 критериям |
| `src/components/estimation/voting-results.tsx` | Отображение результатов (SP, пропорция, средние) |
| `src/components/estimation/ticket-form.tsx` | Форма создания тикета (SM) |
