# Epic 12: Sprint Retrospective Module

## Обзор
Модуль **Sprint Retro** превращает Sprint Planner в замкнутую Agile-экосистему: **Оценка (Planning Poker) → Планирование (Ролевой Гант) → Ретроспектива (Sprint Retro) → Автоматический перенос Action Items в бэклог следующего спринта**.

## Основные возможности

### 1. Доменная модель и шаблоны
- 6 готовых форматов ретроспективы:
  - `WENT_WELL_TO_IMPROVE` (Went well / To improve / Action ideas)
  - `START_STOP_CONTINUE` (Start / Stop / Continue)
  - `MAD_SAD_GLAD` (Mad / Sad / Glad)
  - `FOUR_LS` (Liked, Learned, Lacked, Longed for)
  - `SAILBOAT` (Ветер, Якорь, Рифы, Остров)
  - `CUSTOM` (Свободный формат с динамическими колонками)
- Настройка цветовой палитры колонок (`emerald`, `amber`, `rose`, `blue`, `violet`, `zinc`).
- Добавление, переименование и удаление колонок на лету.

### 2. Фасилитация по 5 фазам
- `COLLECT` (Сбор карточек) — приватный ввод (чужие карточки размыты до раскрытия), анонимный режим, индикатор печати и онлайн-присутствия.
- `GROUP` (Группировка) — Drag-and-drop карточек между колонками и объединение похожих мыслей в именованные группы (`@dnd-kit`).
- `VOTE` (Голосование) — Dot voting с настраиваемым лимитом голосов на участника, скрытием голосов до фазы обсуждения и мгновенным подсчётом.
- `DISCUSS` (Обсуждение) — авто-сортировка колонок по набранным голосам, подсветка активной карточки/группы в фокус всей команды.
- `ACTIONS` & `COMPLETED` (План действий и завершение) — фиксация договорённостей, синхронный таймер фаз со звуковым сигналом (Web Audio API), экспорт в Markdown и CSV.

### 3. Замкнутый цикл с Планером (Closed-Loop Agile)
- **Carry-over Action Items:** при открытии ретро доска показывает статус договорённостей с предыдущих спринтов (`OPEN / DONE`).
- **Конвертация в тикет в 1 клик:** любой Action Item можно мгновенно превратить в `Ticket` планера (в общий бэклог или сразу в активный спринт), после чего задача доступна для оценки в Planning Poker и планирования на Ганте.
- **Шторка контекста спринта:** отображение привязанных задач, суммы Story Points и временного окна спринта прямо во время ретроспективы.
- **RetroToast:** всплывающее уведомление для участников проекта о начале живой ретроспективы.

### 4. Доступ и гостевой режим
- Авторизованные пользователи входят под существующими учётными записями.
- Быстрый гостевой вход по ссылке или QR-коду (`/retro/[token]`) — ввод только имени, без регистрации и пароля.
- Защита маршрутов через `src/proxy.ts` и автоматическая очистка просроченных участников через cron.

### 5. Локализация (i18n)
- 100% паритет всех 754 ключей на 7 языках: `ru`, `en`, `be`, `uk`, `pl`, `es`, `hi`.
