# Эпик 9: Экспорт отчёта по спринту (Sprint Report PDF Export)

## Бизнес-цель
SM и участники команды могут экспортировать PDF-отчёт по спринт-планированию для шаринга с заинтересованными сторонами, архивирования и обсуждения. Отчёт содержит Ганта-чарт, сводку по участникам, таблицу тикетов и опционально — незапланированный бэклог.

## Что реализовано

### Генерация PDF (client-side)
- Библиотеки `jspdf` + `jspdf-autotable` для клиентской генерации векторных PDF.
- Landscape A4 формат, 5 секций: обложка со сводкой, Ганта, разбивка по участникам, таблица тикетов, бэклог.

### Структура отчёта
1. **Обложка + Сводка** — название проекта, спринты, даты, статистика (тикеты, SP, команда, рабочие дни, загрузка).
2. **Ганта-чарт** — статический вариант диаграммы с цветными блоками заданий, маркерами выходных/отпусков, sub-rows для параллельных задач, легендой.
3. **По участникам** — таблица задач каждого участника с SP, длительностью, датами, загрузкой.
4. **Сводка тикетов** — все тикеты спринта с назначенными Dev/QA, днями работы.
5. **Бэклог (опционально)** — SM выбирает конкретные тикеты из бэклога для включения в отчёт.

### Настраиваемый бэклог
- Toggle "Включить бэклог" в диалоге экспорта (выключен по умолчанию).
- При включении показывает список бэклог-тикетов с чекбоксами и поиском.
- Только выбранные тикеты попадают в PDF.

### Multi-sprint выбор
- Диалог экспорта позволяет выбрать несколько спринтов через чекбоксы.
- Активный спринт выбран по умолчанию.

### Выбор языка PDF
- Дропдаун в диалоге экспорта позволяет выбрать язык для PDF-отчёта.
- По умолчанию используется текущий язык интерфейса пользователя.
- Все 7 поддерживаемых языков доступны независимо от языка UI.
- Переводы загружаются напрямую из JSON-файлов через `getReportTranslations()`.

### Доступность
- Кнопка "Экспорт PDF" доступна всем участникам проекта, не только SM.

## Ключевые файлы
| Файл | Назначение |
|---|---|
| `src/lib/report/types.ts` | TypeScript типы для данных отчёта |
| `src/lib/report/generate-sprint-report.ts` | Главный генератор PDF (оркестрация секций) |
| `src/lib/report/draw-gantt.ts` | Отрисовка Ганта-чарта jspdf-примитивами |
| `src/lib/report/color-utils.ts` | Конвертация HSL→RGB для цветов тикетов в PDF |
| `src/app/api/project/[id]/report/route.ts` | API для данных отчёта (спринты, участники, задания, time-offs, бэклог) |
| `src/components/report/export-dialog.tsx` | Диалог экспорта (выбор спринтов, бэклог, генерация) |
| `src/lib/report/get-report-translations.ts` | Загрузка переводов для PDF по выбранному языку |
| `src/components/gantt/gantt-board.tsx` | Интеграция кнопки экспорта в тулбар борда |
