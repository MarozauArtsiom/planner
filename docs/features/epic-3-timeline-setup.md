# Эпик 3: Настройка таймлайна (Timeline Setup)

## Бизнес-цель

Дать Скрам-мастеру возможность создавать спринты (фиксированный цикл Ср–Вт) и визуализировать таймлайн проекта в виде сетки Ганта с осями X (дни, сгруппированные по спринтам) и Y (участники команды, разделённые на Dev и QA). Вся команда видит изменения в реальном времени через HTTP polling.

## Что реализовано

### Story 3.1: Генерация спринта
- SM создаёт первый спринт, выбирая стартовую среду через кастомный мини-календарь (кликабельны только среды).
- Последующие спринты создаются кнопкой "Добавить спринт" — система автоматически приклеивает новый спринт встык к предыдущему.
- Спринт длится 7 календарных дней: Ср 00:00 — Вт 23:59.
- Автоматическая нумерация: Sprint 1, Sprint 2 и т.д. SM может переименовать спринт inline-кликом по заголовку.
- Удаление: только последний (крайний правый) спринт и только если на нём нет тикетов или назначений.

### Story 3.2: Бесконечный скролл Ганта
- Горизонтальный скролл ограничен диапазоном созданных спринтов (в обе стороны).
- При открытии скролл автоматически центрируется на маркере "Сегодня"; если сегодня вне диапазона — на последнем спринте.
- Двухуровневый заголовок: верхний ряд — названия спринтов с цветовой подсветкой (серый = прошедший, синий = текущий, нейтральный = будущий); нижний ряд — дни недели с номерами.
- Выходные (Сб, Вс) выделены приглушённым фоном на всю высоту столбца.
- Маркер "Сегодня" — красная вертикальная линия с точкой на всю высоту сетки.
- Ось Y: sticky-колонка с именами участников, разделённая на секции Dev и QA. SM не отображается как исполнитель.
- Пустое состояние: если спринтов нет, отображается плейсхолдер с кнопкой "Создать первый спринт" (SM) или текстом ожидания (Dev/QA).
- Real-time обновления через HTTP polling (2 сек).
