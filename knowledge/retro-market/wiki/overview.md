# Retro Tools Market — overview

> Living summary of the domain: Исследование рынка инструментов для командных ретроспектив (EasyRetro и аналоги): продукты, фичи, цены, позиционирование, возможности для собственного продукта sprint-retro.
> Rewritten by ingest when the big picture changes. Keep it short; details live in the pages it links to.

## Current picture

- [[entities/easyretro]] — давний простой ретро-инструмент (с 2015, ex-FunRetro) для малых/средних команд; только ретро.
- Модель цен — flat-rate с лимитом досок в месяц, данные противоречивы: [[concepts/easyretro-pricing]].
- Функционал и пробелы (нет AI-кластеризации, слабая аналитика): [[concepts/easyretro-feature-set]].
- Возможности для sprint-retro: [[analyses/easyretro-strengths-weaknesses]].
- Конкуренты: лидер [[entities/teamretro]], open source [[entities/parabol]], free-игроки [[entities/kollabe]] и [[entities/neatro]], остальные — [[entities/niche-retro-tools]]. Цены: [[analyses/competitor-pricing-comparison]]; AI/MCP: [[concepts/ai-in-retro-tools]].
- Непрямые конкуренты: универсальные доски [[entities/whiteboard-tools]] (нет структуры сессии, памяти, анонимности, трекинга action items) и Jira/Confluence-приложения [[entities/atlassian-marketplace-retro-apps]] (малый сегмент по установкам).
- Россия: единственный заметный специализированный игрок — [[entities/retrius]] (1 000 ₽/мес за команду); остальное — доски [[entities/russian-boards-and-trackers]]; факторы выбора — [[concepts/russian-market-factors]].
- Тренды рынка (платформы ритуалов, health checks, AI, MCP, сжатие free): [[concepts/retro-market-trends]]. Гипотезы позиционирования sprint-retro H1–H6: [[analyses/sprint-retro-product-hypotheses]].
